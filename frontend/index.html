Questions people ask

Do I need to sign up?

No. Weave is a working prototype that runs on sample data, so you can try it straight away.

Which apps does it work with?

Today it reads a sample calendar, notes, to-do list and spending statement. Email, fitness, travel and home apps are next.

Can Weave change things on its own?

No. It drafts changes, like a new to-do, and waits for you to approve each one.

What if I switch an app off?

Weave tells you what it couldn’t check instead of guessing.

How does it connect to my apps?

Through MCP, an open standard that lets an assistant use apps you allow. You don’t need to know it to use Weave. Developer mode explains it.
